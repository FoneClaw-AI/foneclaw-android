# FoneClaw 0.3.5

## What's new

- A news workspace brings reports, saved stories and notes together. Bookmark individual stories, add notes and link them to the To-do Center with their news source. Fetch a successful report again for its original date without replacing the earlier result.
- Each conversation remembers its own selected model, so switching one conversation no longer changes the model in another.
- A unified Message Center brings supported task results, recording updates and other in-app notices together. Search, filter read/unread items, mark them read and remove selected entries, with navigation back to the relevant content.
- Spoken replies and news gain pause/resume, speed adjustment and playback navigation. Seeking and previous/next controls are available where the current playback supports them, including media-notification controls.
- Share a single completed question-and-answer pair as a readable public page when the sharing service is enabled. The public projection excludes reasoning, tool traces and attachments, rather than publishing the entire conversation.

## Breaking change: HTTPS required for online models

All online-model addresses must use HTTPS, including localhost, loopback and local-network servers. Existing HTTP addresses must be migrated to a working HTTPS endpoint before saving or connecting. This is a compatibility change, not only a warning in the model editor. Do not upgrade an HTTP-only local-model setup without first arranging HTTPS.

## Service and playback limits

- Public sharing requires matching backend deployment, publication storage and both publication/worker configuration. Publication creation and the worker default to disabled. Guest creation is separately controlled. This release does not imply that sharing is enabled on a production service.
- The backend also supports news-page publication, but the Android news-sharing entry flow is not complete. This is not an end-to-end news-publishing feature in the app.
- Public-page Listen, Report and Subscribe actions, where shown, open app-download guidance only. They do not play audio, submit reports or create subscriptions in the browser.
- Voice point-waiver settings are configurable and default to off. They do not remove account, model-access, moderation or usage restrictions, and do not promise permanently free speech recognition or synthesis.
- News generation, follow-up conversations, speech and linked to-dos remain subject to enabled features, model access, permissions and service availability. Playback controls depend on the current audio's supported operations. Uninterrupted lock-screen playback and recovery after process termination are not guaranteed.

## Distribution scope

- **FoneClaw website:** direct-distribution Android app with online and offline speech variants. Offline speech does not make online AI or news services available offline.
- **Google Play:** online-speech build with Play billing and updates. Shared news, per-conversation model selection, Message Center and recording surfaces remain included. Floating-assistant controls and direct-only cross-app capabilities are not Play features. Toolbox browsing does not imply external Android plugin installation or execution. Play availability depends on its own review and rollout.
- **CN website:** separate domestic app and update infrastructure, with explicit privacy choices and no Firebase. Its domestic toolbox catalog and shared GitHub plugin repository are independent sources. GitHub plugin availability depends on network access. The CN APK is not a default public GitHub Release asset.
- Lebest is discontinued and is not part of this release. Backend deployment and configuration remain separate from Android distribution.
