# v0.2.2 Release Notes

**Status:** Release candidate  
**Release date:** September 16, 2026  
**Compared with:** v0.2.1  
**Version code:** 23  
**Default APK:** Online TTS release

## Highlights

- Added a redesigned getting-started guide with interactive examples that make key features easier to discover.
- Added a Plugin Marketplace and improved model selection with clearer controls and navigation.
- Added Telegram connection support so FoneClaw conversations can continue through a linked Telegram bot.
- Improved live response display, navigation, the To-do Center, and calendar presentation.
- Improved scheduled-task reliability with cloud recovery and notifications when local runs are missed.
- Improved email searches so precise filters are preserved and failed searches no longer return unrelated broader results.
