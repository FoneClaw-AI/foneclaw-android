- Completed member system and notification updates with backend API v1 integration.
- Added distribution-specific builds for FoneClaw, Google Play, and Lebest platforms.
- Improved home page UI with refined neutral chat chrome and settings page visual unification.
- Fixed voice state initialization before collection and terminal ASR polling failures.
- Optimized recording experience with fixes for horizontal bar flashing and duplicate prompts.
- Enhanced extension refresh and release metadata management.
- Stabilized recorder cleanup after merge and improved Skill usage feedback review.
- Updated documentation with v0.1.5 release candidate hashes and build constraints.

## Tool Catalog

- The public catalog contains 118 built-in tools across 11 categories and 15 locale files.
- The `screenshot_take` description now reflects that captured images are kept in app-private cache for Agent use and are not added to the system Gallery.
- The catalog index records the `/FoneClaw/ToolPolicy/` paths, sizes, and SHA-256 values for the default English catalog and all localized catalogs.

## Known Limitations

- This is a GitHub Pre-release and is not a Google Play release.
- The app targets Android API 28 and requires Android 9 or newer.
- Android versions below 11 cannot use AccessibilityService screenshot capture. Secure windows, the lock screen, or system restrictions can also block capture.
- Some OEM background, auto-start, and power-saving policies may require additional setup for reliable floating-assistant availability.
- Focused App and Core unit-test tasks are currently blocked at test-source compilation by stale test calls. The production Release variants, lint, signatures, and alignment checks passed.
- Device evidence for the floating assistant comes from development-stage checks on vivo, Samsung, and Xiaomi devices; a fresh release-run full-device regression was not performed.
