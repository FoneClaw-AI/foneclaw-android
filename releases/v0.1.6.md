# v0.1.6 Release Notes

**Status:** GitHub Release<br>
**Release date:** August 21, 2026<br>
**Compared with:** v0.1.5<br>
**Version code:** 17<br>
**Default APK:** Online TTS release

## Highlights

- Added reliable image attachment and captured-image reanalysis flows with stable file URLs and safer OSS authorization.
- Improved screenshot and camera results so images, dimensions, and local or remote references remain available for follow-up Agent tasks.
- Improved multimodal request preparation, image token budgeting, prompt compression, and attachment renewal before LLM calls.
- Improved cross-app progress feedback and made reasoning details easier to follow during longer tasks.
- Added comprehensive LLM event diagnostics while protecting sensitive request content.
- Improved mail list execution limits and prevented failed OSS attachments from reaching LLM requests.
- Improved public Tool Catalog wording and regional Chinese localization consistency.
- Hardened the multi-channel release process with project-managed validation, dry-run, and rollback contracts.

## Known Limitations

- Google Play and Lebest candidates are tracked separately and are not part of this FoneClaw GitHub Release.
- Google production metadata must wait for the Play version to become live.
- Lebest production metadata must wait for OEM re-signing and device upgrade verification.
- A fresh full-device regression was not performed during this release run.
