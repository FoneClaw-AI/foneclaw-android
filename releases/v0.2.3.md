# v0.2.3 Release Notes

**Status:** Release candidate  
**Release date:** September 20, 2026  
**Compared with:** v0.2.2-fix  
**Version code:** 25  
**Default APK:** Online TTS release

## Highlights

- Added a redesigned Telegram connection experience with clearer setup, connection status, and localized guidance.
- Added scheduled Automations with local execution, cloud recovery, notifications, and safer missed-run handling.
- Added richer voice notes and transcription summaries with clearer layouts and easier review.
- Added Discord connectivity and improved social-channel approval, progress, and delivery handling.
- Improved the To-do Center, plugin workspace, model picker, subscription flows, and agent messaging.
