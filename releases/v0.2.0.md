# v0.2.0 Release Notes

**Status:** Release candidate  
**Release date:** September 7, 2026  
**Compared with:** v0.1.9  
**Version code:** 21  
**Default APK:** Online TTS release

## Highlights

- Follow delegated tasks more clearly with live progress and cleaner results.
- View SMS results and web sources in a more organized, readable format.
- Manage custom AI models more easily with a dedicated section and direct editing.
- See clearer upgrade pricing, current-plan credit, availability, and renewal details.
- Set up Gmail accounts more reliably with guided configuration.
