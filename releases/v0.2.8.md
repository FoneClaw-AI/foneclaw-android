# FoneClaw v0.2.8

## What's New

- Review and update saved shortcuts when their underlying actions have changed, then choose whether to save and run the updated shortcut.
- Follow a new recording guide to add the Quick Settings button and check the permissions needed for recording.
- Find scheduled tasks by searching their names or instructions, review their schedules, and see when a Run now request is already pending.
- Request account deletion from the account screen using an email verification code. Eligibility may be affected by active subscriptions or other account conditions; deleting an account does not cancel a subscription.
- Turn spoken responses on or off from Home, and start a new conversation from the top bar. Online speech playback has also been improved.
