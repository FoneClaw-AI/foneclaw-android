# v0.1.2 Release Notes

**Status:** GitHub Pre-release<br>
**Release date:** August 7, 2026<br>
**Compared with:** v0.1.1<br>
**Version code:** 12<br>
**Default APK:** Online TTS release

## Highlights

- Added a floating assistant with a movable bubble and compact panel for using FoneClaw from
  other apps.
- Added one-tap current-screen attachment from the floating panel while keeping FoneClaw
  overlays out of the captured image and storing the image only in app-private cache.
- Improved task continuity between Home and the floating assistant with shared execution,
  approvals, stopping, and permission recovery.
- Improved Do Not Disturb, volume, meeting-mode shortcuts, and screenshot reliability with
  clearer post-action state checks.
- Added initial quick actions so common tasks are easier to discover and start.
- Expanded privacy-safe product analytics without collecting prompts, messages, personal
  content, screenshots, or account identifiers.

## Tool Catalog

- The public catalog contains 118 built-in tools across 11 categories and 15 locale files.
- The `screenshot_take` description now reflects that captured images are kept in app-private
  cache for Agent use and are not added to the system Gallery.
- The catalog index records the `/FoneClaw/ToolPolicy/` paths, sizes, and SHA-256 values for the
  default English catalog and all localized catalogs.

## Known Limitations

- This is a GitHub Pre-release and is not a Google Play release.
- The app targets Android API 28 and requires Android 9 or newer.
- Android versions below 11 cannot use AccessibilityService screenshot capture. Secure windows,
  the lock screen, or system restrictions can also block capture.
- Some OEM background, auto-start, and power-saving policies may require additional setup for
  reliable floating-assistant availability.
- Focused App and Core unit-test tasks are currently blocked at test-source compilation by stale
  test calls. The production Release variants, lint, signatures, and alignment checks passed.
- Device evidence for the floating assistant comes from development-stage checks on vivo,
  Samsung, and Xiaomi devices; a fresh release-run full-device regression was not performed.
