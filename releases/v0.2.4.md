# v0.2.4 Release Notes

**Status:** Release candidate  
**Release date:** September 22, 2026  
**Compared with:** v0.2.3  
**Version code:** 26  
**Default APK:** Online TTS release

## Highlights

- Added push notifications so reminders and important updates reach you even when the app is in the background.
- Added a Quick Settings tile to start or stop voice-note recording from the notification shade.
- Made voice notes easier to review and edit with clearer transcription layouts.
- Redesigned the Discord connection setup with clearer status and step-by-step guidance.
- Added Agent behavior styles (Precise, Balanced, Creative) and an in-app FAQ, with clearer error messages and faster conversation switching.
