# v0.1.3 Release Notes

**Status:** GitHub Pre-release<br>
**Release date:** August 14, 2026<br>
**Compared with:** v0.1.2-fix<br>
**Version code:** 14<br>
**Default APK:** Online TTS release

## Highlights

- Improved floating assistant overlay behavior with better top bar display cutout insets and transparency.
- Added user action bar and user action controller for enhanced assistant interaction.
- Enhanced reply content with free-range copy selection, and added copy, feedback, and share retry buttons to floating window.
- Added GUI page with drag support, permission recovery, and GUI foreground permission interception.
- Improved system screenshot summary monitoring and cross-app/screenshot planning with failure message formatting.
- Unified assistant interaction experience with improved recording and shortcut functionality.
- Added SkillImportPreviewer with related unit tests for better skill management.
- Improved analytics with intent and permission outcome classification, and floating assistant task entry tracking.
- Optimized global three-button white background logic, shortcut/recording sliding effects, and approval card UI.
- Added Direct vs Google Play distribution isolation at compile time.

## Tool Catalog

- The public catalog contains 118 built-in tools across 11 categories and 15 locale files.
- The `screenshot_take` description now reflects that captured images are kept in app-private cache for Agent use and are not added to the system Gallery.
- The catalog index records the `/FoneClaw/ToolPolicy/` paths, sizes, and SHA-256 values for the default English catalog and all localized catalogs.

## Known Limitations

- This is a GitHub Pre-release and is not a Google Play release.
- The app targets Android API 28 and requires Android 9 or newer.
- Android versions below 11 cannot use AccessibilityService screenshot capture. Secure windows, the lock screen, or system restrictions can also block capture.
- Some OEM background, auto-start, and power-saving policies may require additional setup for reliable floating-assistant availability.
- Focused App and Core unit-test tasks are currently blocked at test-source compilation by stale test calls. The production Release variants, lint, signatures, and alignment checks passed.
- Device evidence for the floating assistant comes from development-stage checks on vivo, Samsung, and Xiaomi devices; a fresh release-run full-device regression was not performed.
