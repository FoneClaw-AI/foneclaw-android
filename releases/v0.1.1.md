# v0.1.1 Release Notes

**Status:** GitHub Pre-release<br>
**Release date:** August 5, 2026<br>
**Compared with:** v0.1.0<br>
**Version code:** 11<br>
**Default APK:** Online TTS release

## Highlights

- Added multi-conversation management with recent sessions, switching, renaming, clearing,
  persistent unread state, and improved long-conversation browsing.
- Added a strict cross-conversation FIFO queue with independent running and waiting states so
  requests remain bound to the conversation where they were submitted.
- Improved continuous history loading, automatic scrolling, mail presentation, long-text actions,
  URL recognition, and custom shortcut feedback.
- Strengthened session-bound approvals, task isolation, permission recovery, voice input, and
  tool-returned image persistence and upload.
- Reorganized the Home execution flow into focused coordinators for more reliable task completion,
  cancellation, and recovery.
- Retained a provisional trusted-plugin path for YouTube links for continued validation. This is
  an alternative path, not the final solution; the complete handling design remains in progress.

## Tool Catalog

- The public catalog contains 118 built-in tools across 11 categories and 15 locale files.
- The `mail_list` description now requires a fresh tool call for every new list, search, filter,
  date-range, summary, or reformat request; historical message references remain limited to an
  exact message already selected by the user.
- The catalog index records the `/FoneClaw/ToolPolicy/` paths, sizes, and SHA-256 values for the
  default English catalog and all localized catalogs.

## Known Limitations

- This is a GitHub Pre-release and is not a Google Play release.
- The app targets Android API 28 and requires Android 9 or newer.
- Fresh full-device regression for multi-conversation FIFO, cancellation, approval isolation,
  recording, transcription, and tool image upload is still pending.
- The latest App and Core focused unit-test tasks are blocked by test sources that still call
  removed parameters or repository methods. The previous executable baseline also contains ten
  accepted failures; this release must not be treated as a fully green test baseline.
- Cross-app screen reading remains classified as `LOW/AUTO` in the current catalog while a prior
  test expects sensitive read with approval. This policy difference remains a P0 review item.
- The YouTube trusted-plugin path is provisional and still requires a unified final solution and
  broader device, format, recovery, storage, and licensing validation.
