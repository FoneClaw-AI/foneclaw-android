# FoneClaw v0.3.0

## What's New

- Redesigned the sidebar with conversation-title search and easier access to your tools.
- Browse the refreshed Plugin Marketplace by category, save favorites, and revisit recently used entries.
- Improved fallback handling when web search or page retrieval is unavailable, and fixed source-link presentation.
- Follow spoken replies with text highlighting and smoother continuous playback of long responses.
- Ask in chat to modify saved travel plans, with clearer generation progress and retry handling.
- Improved synchronization of scheduled-task exception reminders when the supporting service is available.
- Get clearer insufficient-points prompts and recording-transcription failure messages.

## Availability and scope

- Online and Offline identify speech-synthesis variants. Offline TTS does not mean offline AI model access or offline web services.
- Service-dependent search and scheduled-task reminder improvements require the corresponding services to be available; production deployment has not been verified.
- Google APK/AAB remain Play submission candidates until version 0.3.0 (32) is verified live in Production. The AAB is not a default GitHub asset. [Google Play listing](https://play.google.com/store/apps/details?id=ai.foneclaw.lite).
- Lebest remains a locally signed OEM candidate, not a final OEM package, and is not a default GitHub asset.
- The new Domestic channel (`cn.android.claw`) has no Firebase or Gmail integration. It has not officially launched; its distribution bucket is unconfirmed and its APK is not a default GitHub asset.
- FoneClaw Online APK: VirusTotal reported 0/57 flagged engines for this exact artifact ([report](https://www.virustotal.com/gui/file/50ca2804b5492f6a03700abe36a888c39f4a3c1d930f0cf4bb93d4ca0df7e253)). This scan snapshot does not cover the other downloads or guarantee safety.
