## Availability and scope

- Online and Offline identify speech-synthesis variants, not offline AI model or web-service availability.
- Google APK/AAB remain submission candidates; Production availability of `0.3.0-fix (33)` is unverified. The AAB is not a default GitHub asset. [Google Play listing](https://play.google.com/store/apps/details?id=ai.foneclaw.lite).
- Lebest remains a locally signed OEM candidate, not an official OEM package or default GitHub asset.
- The Domestic channel has not officially launched. Its distribution bucket is unconfirmed and its APK is not a default GitHub asset.
- VirusTotal snapshot for `app-onlineTts-release.apk` only: **0/68** engines flagged this exact APK ([report](https://www.virustotal.com/gui/file/67b89c1af6a8047c5f339046b06e1434448906efedd054374e48d15cb52e740a)); report timestamp: `1792578251`. This snapshot does not cover the Offline TTS APK or any other artifact and is not a safety guarantee.
- Scope is limited to the brand slogan and built-in tool compatibility; broader fault resolution and full device regression have not been verified.
