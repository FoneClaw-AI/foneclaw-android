# v0.1.7 Release Notes

**Status:** GitHub Release<br>
**Release date:** August 26, 2026<br>
**Compared with:** v0.1.6<br>
**Version code:** 18<br>
**Default APK:** Online TTS release

## Highlights

- Added a persistent Information Inbox for notifications, SMS, call logs, calendar events, and mail, with source status, search, filters, refresh, review, and delete actions.
- Added a complete Memo management page with local search, editing, status switching, multi-select deletion, and shared real-time data with Agent tools.
- Added FoneClaw Plus entitlement and iCart purchase flows, with bootstrap-based capability access and pending upgrade recovery.
- Improved Home, floating assistant, recordings, shortcuts, Markdown rendering, copy blocks, deletion interactions, and dark-theme consistency.
- Separated member endpoints by build type and aligned backend bootstrap, entitlement, retry, and capability access behavior.
- Improved SysInfo persistence and collection reliability for mail, notifications, SMS, call logs, and calendar data.
- Fixed notification icon rendering, reply copy actions, image attachment resolution, approval interactions, recording cleanup, and ASR behavior.
- Hardened the multi-channel release workflow with deterministic metadata, artifact verification, remote publication checks, and rollback planning.
