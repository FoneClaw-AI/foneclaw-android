# FoneClaw Android v0.3.2

FoneClaw 0.3.2 improves voice memos, playback, result reminders, news reading, and streaming chat.

- Review voice memo collections by chapter, create action items from chapter takeaways, open transcript files from background result notifications, and export from the detail page.
- Choose device-language voice recommendations, browse more voices and filters, preview voices independently, and adjust volume.
- See lightweight red-dot reminders for new plugin and scheduled-task results, then mark results read one by one from their original pages.
- FoneClaw's confirmed GUI action segments can continue through keyboard input and submit/send actions while retaining approval and cancellation boundaries.
- Read news results more clearly and follow smoother streaming chat updates.
- Flash chat runs without tools; standard model roles expose only supported capabilities.

This release does not claim seamless lock-screen playback, uninterrupted resume after process or system termination, or completed production backend deployment. Google Play publication and review are separate channel gates.
