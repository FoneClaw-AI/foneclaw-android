# v0.1.2-fix Release Notes

**Status:** GitHub Pre-release<br>
**Release date:** August 7, 2026<br>
**Compared with:** v0.1.2<br>
**Version code:** 13<br>
**Default APK:** Online TTS release

## Highlights

- Improved the floating assistant's window sizing, keyboard handling, outside-touch collapse,
  and permission recovery across supported Android devices.
- Added the first Plugin and Skill capability-routing foundation with Manifest v2 matching,
  dependency declarations, context metadata, and local deterministic routing.
- Added AutoAttach, Suggest, and Fallback modes without automatically executing Tools or bypassing
  approval policies.
- Added plugin activation review, Pending Activation handling, and atomic capability snapshots so
  a failed refresh keeps the last accepted capability set.
- Added explicit Skill learning with preview and confirmation before saving a disabled draft.
- Upgraded the YouTube Downloader Plugin to `0.0.3 (3)` and its Manifest/Skill v2 contract.

## Plugin Update

- YouTube Downloader Plugin `0.0.3 (3)` was built as a Release APK and added to the public plugin
  index with SHA-256 `83839975dd3c0cf61af437d85711483be09df245e3647d896525bb147d3131d6`.

  default capability-routing rollout.

## Known Limitations

- This is a GitHub Pre-release and is not a Google Play release.
- Plugin/Skill routing still needs complete corpus, Tool V2, installation recovery, File Manager
  split, and multi-device validation before it can be treated as a complete MVP.
- A fresh GitHub-download device flow for plugin discovery, installation, and YouTube delivery was
  not completed in this publication; the plugin is published for continued validation.
- Focused App/Core full unit-test tasks retain existing stale test-contract blockers; production
  Release builds and Plugin targeted JVM tests passed.
- OEM background, auto-start, and power-saving policies may require additional setup for the
  floating assistant.
